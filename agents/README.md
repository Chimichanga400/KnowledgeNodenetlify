# Your AI Agent Team

Five agents that run the admin side of KnowledgeNode so you only spend
~15 hours/week on the business. Each file is a complete system prompt.

## How to use them

1. Open Claude (claude.ai) → create a **Project** per agent (or one recurring
   chat per agent).
2. Paste the agent's file into the Project's custom instructions.
3. Start each session with the trigger phrase at the top of the file, plus any
   inputs it asks for.
4. The agent returns its outputs in a fixed format — you approve/act, done.

## The team

| Agent | Run | Your time per run |
|---|---|---|
| `ops-admin-agent.md` | Daily | 10–15 min |
| `support-agent.md` | Daily (with inbox pasted in) | 10 min |
| `marketing-agent.md` | Mon + Thu | 30 min (approve + post) |
| `research-agent.md` | Weekly (Fri) | 20 min (read brief) |
| `finance-agent.md` | Weekly (Mon, with numbers pasted in) | 15 min |

**Total: roughly 6–8 hours/week of your time** on agent-driven ops, leaving the
rest for sales calls and posting content.

## Rules that apply to every agent

- Agents **draft**, you **send**. Nothing goes to a customer, a bank, or the
  public without your approval.
- Agents never invent numbers. If an input is missing, they must ask for it.
- Anything involving money out (refunds, spend above R500) is escalated to
  you with a recommendation, never decided by the agent.
